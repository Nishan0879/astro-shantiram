# Astro Shantiram

Website for Acharya Shantiram Koirala: astrology, puja, consultations and spiritual knowledge, in English, नेपाली and संस्कृतम्.

The full product spec lives in [docs/spec.md](docs/spec.md).

## Status

Phase 1: public site plus the first API endpoint.

| Part | State |
| --- | --- |
| `frontend/` | Next.js 16 (App Router, TypeScript, Tailwind 4, next-intl). Home, About, Services and Contact in `/en`, `/ne`, `/sa`. |
| `backend/` | Express 5 + TypeScript API with Drizzle ORM on PostgreSQL. `GET /api/health`, `POST /api/contact` (saves the message, emails a notification when SMTP is set). |
| `database/migrations/` | SQL migrations generated by Drizzle from `backend/src/db/schema.ts`. |

The website's contact form posts to the API when `API_URL` is set, and only logs messages when it isn't.

## Run locally

You need Node 20+ and a PostgreSQL database.

```bash
# API on http://localhost:5000
cd backend
cp .env.example .env        # set DATABASE_URL
npm install
npm run db:migrate          # create the tables
npm run dev

# Website on http://localhost:3000
cd frontend
cp .env.example .env.local  # API_URL=http://localhost:5000
npm install
npm run dev
```

The site redirects to `/en`, or to `/ne` / `/sa` based on the browser language.

Backend tests run against an in-memory Postgres (PGlite), so they need no database: `cd backend && npm test`.

## Changing the database

Edit `backend/src/db/schema.ts`, then run `npm run db:generate` to write a new migration and `npm run db:migrate` to apply it.

## Translations

UI text lives in `frontend/messages/{en,ne,sa}.json`. The Nepali and Sanskrit strings were drafted by machine and need review by a native speaker.
